# FloraHomely

A clean, lightweight, and responsive HTML landing page for **[FloraHomely.com](https://florahomely.com)** hosted on GitHub Pages. This landing page introduces visitors to FloraHomely's core botanical categories, styling philosophy, and site guides.

---

## 🌿 Overview

This repository contains the single-page web deployment for **FloraHomely** built with vanilla HTML5 and CSS3. It mirrors the core brand aesthetics, card layouts, and typography established on the main website.

* **Live Landing Page:** `[https://github.com/hugogeorgeofficial/florahomely/](https://github.com/hugogeorgeofficial/florahomely/)
* **Main Website:** [FloraHomely.com](https://florahomely.com)

## 📄 Structure & Features (`index.html`)

1. **Sticky Header Navigation:**
   * Custom brand logo (`FloraHomely`) with dual-color typography.
   * Quick navigation links directly mapped to main site categories.

2. **Hero Showcase:**
   * Gradient background card (`#F9F8F3` to `#EFEBE4`).
   * Prominent call-to-action button linking directly to [FloraHomely.com](https://florahomely.com).

3. **Interactive Category Grid (4 Core Cards):**
   * **🌸 Flowers:** Links to `/flowers/`
   * **🪴 Plants:** Links to `/plants/`
   * **🏡 Garden:** Links to `/garden/`
   * **🛠️ Care Tips:** Links to `/care-tips/`
   * *Features elevation hover transitions (`translateY(-5px)`) and soft custom drop shadows.*

4. **Brand Purpose Section:**
   * Highlight card detailing FloraHomely's mission to make indoor plant care and botanical styling easy for everyone.

5. **Responsive Design:**
   * Fully responsive layout using CSS Grid and Flexbox with breakpoints for mobile (`480px`) and tablet (`768px`) screens.
